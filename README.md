# Roast Your Own Agent

One original line roasting my own AI agent, for the
[make.fun bounty](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda).

## The roast

> My agent treats every task like a heist movie: three hours of planning, one nervous minute of doing it, and a getaway plan for a file it never stole.

## How it is built

`main.ts` (Node 22) is a deterministic program: it writes that one fixed
line to `/output/entry.txt`. No network, no clock, no randomness — run it
twice and the outputs are byte-identical (149 characters, one line).
